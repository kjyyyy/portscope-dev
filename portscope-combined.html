Vision & Value Proposition

Portscope replaces the fund administrator for small family offices (AUM $50M–$500M). The core value chain:

  1. Documents arrive (capital calls, distributions, NAV statements, K-1s) via upload or email.
  2. AI extracts structured data — fund name, amount, dates, routing numbers — with confidence scores.
  3. Staff review only fields the AI is uncertain about (flagged below 85% confidence).
  4. Approved data flows into portfolio holdings, capital events, and reporting automatically.
  5. Quarterly reports are generated and delivered to family members via a branded client portal.

Personas

Staff Analyst (Persona)

Reviews flagged documents, corrects extraction errors, approves capital events. Sees the review queue and document detail pages.

Family Principal (Persona)

Checks portfolio value, reviews quarterly reports, downloads PDFs via a branded client portal accessed via magic link.

Confidence Scoring

4-tier system combining LLM self-reported confidence with heuristic validation:

TierRangeActionVisual
High≥ 95%Auto-approve (if all fields high)Green badge
Good85–94%Accept, surface for reviewBlue badge
Review70–84%Flag for human reviewAmber badge + ⚠
Must verify< 70%Require manual correctionRed badge + ✕

Heuristic Validators

  • Money fields: Strips $, and checks parseable float > 0
  • Date fields: Regex matches ISO, US, and named formats
  • Routing numbers: Must be exactly 9 digits
  • EINs: Must be exactly 9 digits
  • Percentages: Must be 0–100 range

Upload Flow

POST /api/documents/upload (multipart/form-data with 'file' field)
  1. Upload file to MinIO → s3Key
  2. Create Document record (status=PROCESSING)
  3. Background: call extractor /classify → /extract
  4. Update Document with fields, confidence, status (REVIEW or AUTO_APPROVED)
  5. Return document record immediately (processing continues async)

PDF Processing Pipeline

_get_document_text(s3_key):
  1. Try S3/MinIO download (boto3)
  2. Parse PDF → text (pdfplumber)
  3. Fallback: local file at /tmp/documents/<s3_key>
  4. Fallback: placeholder text for testing

Temporal Workflows

The ingestDocumentWorkflow orchestrates the full document pipeline:

async function ingestDocumentWorkflow(input):
  1. classifyDocument(s3Key)        # Activity: call extractor /classify
  2. extractDocument(s3Key, type)   # Activity: call extractor /extract
  3. storeExtraction(docId, fields) # Activity: update DB
  4. if overallConfidence ≥ 0.95:
       → AUTO_APPROVED
  5. else:
       → notifyReview(docId)        # Activity: email/notify
       → await approvalSignal       # Blocks until human approves
  6. if corrections:
       → storeCorrections(docId)    # Activity: save for training
  7. persistCapitalEvents(docId)    # Activity: create Holding/Event records

Authentication

Staff

  • JWT-based authentication via Authorization: Bearer <token>
  • Dev mode: Bearer dev-token bypasses JWT validation and maps to seeded staff user
  • Next.js middleware allows access to review routes in development

Client

  • Magic link authentication: /portal?token=<magic-link-token>
  • Middleware sets ps-portal-session cookie on first visit with token
  • Dev mode: portal is accessible without token

How to Start

Option 1: Web UI Only (No Backend)

cd portscope-dev
pnpm install
pnpm --filter @portscope/web dev
# Open http://localhost:3000/queue

Option 2: Full Stack with Ollama (Free, Local AI)

# Prerequisites: Docker, Node 20+, pnpm 9+, Python 3.11+, Ollama

# 1. Infrastructure
docker compose up -d

# 2. Database
pnpm install
cd packages/db && npx prisma generate && npx prisma db push && cd ../..

# 2b. Seed demo data (one-time)
curl -X POST http://localhost:3001/api/seed

# 3. Extractor (in a new terminal)
cd apps/extractor
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
ollama pull llama3.1:8b
LLM_PROVIDER=ollama uvicorn src.api.main:app --port 8001 --reload

# 4. Web + API (in a new terminal)
pnpm dev

# 5. Open browser
# Staff: http://localhost:3000/queue
# Portal: http://localhost:3000/portal
# Extractor: http://localhost:8001/docs (Swagger UI)
# Temporal: http://localhost:8080
# MinIO: http://localhost:9001

# In .env:
LLM_PROVIDER=openrouter
LLM_API_KEY=sk-or-v1-your-key
LLM_MODEL=anthropic/claude-3.5-sonnet
